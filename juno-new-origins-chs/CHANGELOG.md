# 更新日志

## v1.0.2 — 2026-09-24

**修复：语言包是非法 XML（「有声音但黑屏」的真正原因）**
- `Strings.xml` 头部注释里写了命令行参数 `--detect`。**XML 规范禁止注释中出现连续两个连字符**，
  这使整个语言包变成非法 XML —— 严格解析器会拒绝整份文件，游戏加载语言包失败。
  在部分机器上表现为「有声音但黑屏」；在另一些机器上游戏静默回落英文且不报任何错误
  （所以「日志无错误」并不等于「汉化生效」）。
- 修复：注释改写为不含 `--` 的表述，并补上 `<?xml version="1.0" encoding="utf-8"?>` 声明。
- `build_zh_cn.py` 写入后立即用 `ElementTree` 严格解析回读，非法即中止构建。

**字体瘦身（消除图集/内存压力）**
- 原始字体含 31036 个字形 / 30890 个字符映射；TextMeshPro 的 2048x2048 图集在 60px 采样下
  只容得下约 800 个字形，加载时还要为 3 万字形建立查找表。
- 新增 `subset_font.py`：按「GB2312 全集 + 游戏实际用字 + ASCII + 标点」裁剪，
  字形 31036 → 7374（-76%），体积 10.6 MB → 2.1 MB，署名 name 表完整保留。

**Fonts.xml 加固**
- 去掉文件内所有注释（消除编码/解析歧义），补 XML 声明。
- `samplingPointSize` 60 → 48：图集可容纳字形数从约 800 提升到约 1160。

## v1.0.1 — 2026-09-23

**兼容性修复（重要）**
- **移除对 `resources.assets` 的修改**。该操作只是把主菜单版本号从右上角移到右下角，
  但实测该元素在游戏里根本不渲染（零可见收益），却需要直接改写 Unity 二进制资源文件；
  在游戏版本与验证版本不一致的机器上可能命中错误的元素，导致资源损坏（表现为黑屏）。
  旧版安装包改过的文件，运行「卸载还原」可从 `.orig` 恢复。
- **新增诊断工具** `诊断-黑屏排查.bat`：一键收集系统 / 显卡 / 游戏文件状态 / 语言包 / Unity 日志，
  输出报告到桌面，用于定位「有声音但黑屏」这类问题。
- 修复诊断脚本中 `$gamedir` 与参数 `$GameDir` 同名导致参数被清空的 bug
  （PowerShell 变量名不区分大小写）。

## v1.0.0 — 2026-09-23

首个正式版本。

**汉化**
- 完成全部 9318 条界面文本翻译（100%）
- 覆盖：主菜单、设置、建造器、零件、行星工坊、生涯合约、教程、飞行界面、Vizzy 可视化编程
- 21 个批次并行翻译 + 术语表约束 + 自动化格式校验

**技术**
- 建立 `checklib.py` 校验核心，覆盖 6 类游戏专有格式记号：
  占位符 `{0}`、`@记号`、`%记号%`、`|绑定记号|`、方括号标记 `[highlight]`、Vizzy 参数标注 `(N:Type)`
- 处理了英文源里 11 个自带 `&` / `'` 的 id（未转义会导致整个语言包失效）
- 区分真换行与字面量 `\n` 两种换行语义

**字体**
- 改用 OFL 许可的 Noto Sans SC 静态实例（原 SimHei 许可禁止修改再分发）
- 字体 name 表写入作者署名

**署名**
- 7 层署名：主菜单版本号（DLL IL 补丁）、菜单「制作人员」、语言标签、
  19 条译文内嵌零宽字符水印、字体元数据、文件头、签名文件
- 提供 `verify_signature.ps1` 供核验出处

**打包**
- 一键安装 / 卸载 / 仅语言包安装 / 署名验证四种入口
- 安装器带版本检测与安全回退：结构与验证版本不符时自动跳过，绝不损坏游戏
- 安装包实测：全新安装 → 卸载（SHA256 完全还原）→ 再安装 全通过
