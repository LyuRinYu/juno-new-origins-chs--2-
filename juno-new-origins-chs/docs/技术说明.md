# Juno: New Origins 简体中文语言包 —— 汉化工作目录

**状态：全量完成 9318 / 9318 条（100%）** · 已安装并可游戏内切换

游戏自带官方多语言系统，本汉化**不改游戏安装目录一个字节**，只在用户数据目录放语言包。
安装位置：`%USERPROFILE%\AppData\LocalLow\Jundroo\SimpleRockets 2\Languages\ZH-CN\`

---

## 一、怎么用

1. 启动游戏 → **设置 → 通用 → 语言 → ZH-CN**
2. 语言包已随本目录的构建脚本自动安装；改完任何东西跑一次 `python build_zh_cn.py` 即可
3. 卸载/回滚：删掉 `Languages\ZH-CN` 文件夹即可（游戏安装目录零改动）

## 三、术语修正（三条路）

```bash
# ① 全局换一个词的译法
python replace_term.py 载具 飞行器          # 先预览会改多少条
python replace_term.py 载具 飞行器 --write  # 确认替换并自动重建

# ② 逐条精修（改某几条）
python export_review.py                     # 生成 校对对照表.tsv
#    Excel 打开，在「修改列(填这里覆盖)」填新译文，保存
python import_revisions.py                  # 回灌 + 校验 + 重建

# ③ 只看某模块 / 只看没翻的
python export_review.py --module Career
python export_review.py --untranslated
```

改了 `glossary.tsv` 只影响后续翻译；**已翻译部分请用 ① 批量替换**。

## 五、署名信息（防抹除设计）

语言包与补丁内置 **7 层**作者署名，抹除需要逐层处理，其中两层无法用文本编辑器发现：

| 层 | 位置 | 抹除难度 |
|---|---|---|
| 1 | **主菜单版本号后缀** —— 显示为 `v1.4.104  ·  LyuRinYu汉化`（游戏 DLL 内 IL 补丁） | 需改 dll 二进制 |
| 2 | **主菜单「菜单」→「制作人员」** 条目 = `制作人员 · LyuRinYu汉化` | 需逐条改译文 |
| 3 | **设置 → 通用 → 语言** 标签 = `语言（LyuRinYu 汉化）` | 需逐条改译文 |
| 4 | **19 条译文内嵌零宽字符水印**（U+200B/U+200C 编码 `LyuRinYu-JNO-CHS`） | **肉眼与普通编辑器完全不可见**，需专门检测零宽字符才能定位 |
| 5 | **字体文件 name 表元数据**（UniqueID / Manufacturer / Designer / Description 等） | 需改字体二进制 |
| 6 | `Strings.xml` / `Fonts.xml` 文件头 + `SIGNATURE.txt` | 易删，但增加清理成本 |
| 7 | 字体文件名 `JNOSansSC-Regular.ttf` 与字体家族名 `JNO Sans SC` | 易改 |

**验证作者身份**（用于他人搬运后举证）：
```bash
python apply_signature.py --detect    # 扫译文水印，应解码出 LyuRinYu-JNO-CHS
python prepare_font.py --show         # 读字体元数据署名
```

说明：纯文本类内容理论上都能被替换，所以"无法轻易抹除"靠的是**冗余 + 隐形**——普通搬运者既看不到水印，也不会想到去改字体二进制和游戏 dll。

## 六、安全与回滚

- 语言包部分：**不改游戏安装目录一个字节**（无注入、无 BepInEx），不影响存档/成就/云同步
- 语言包位于用户数据目录，**游戏更新不会覆盖汉化**
- **完全回滚**：
  ```bash
  python restore_dll.py        # 还原被补丁的 SimpleRockets2.dll
  # 再手动删掉 Languages\ZH-CN 文件夹；若改过语言设置，还原 Settings.xml.bak_jnochs
  ```
- 补丁涉及的两个游戏文件均已自动备份：
  - `SimpleRockets2_Data\Managed\SimpleRockets2.dll.orig`（原始 dll）
  - `SimpleRockets2_Data\resources.assets.orig`（原始 UI 布局，仅把版本号从被遮挡的右上角移到右下角）
- 字体：`JNOSansSC-Regular.ttf`（由 `prepare_font.py` 从系统 Noto Sans SC 实例化的静态字重，OFL 许可，可自由修改分发）。必须 `atlasPopulationMode="Dynamic"`。想换回系统黑体：把 `Fonts.xml` 的 `file` 改成 `SimHei.ttf`

## 七、致谢与注意

- 本语言包由机器批量翻译 + 术语表约束 + 自动化校验生成，**术语一致性经扫描验证**，但长句与谐音梗仍需人工润色
- 发现别扭的译文：用上面第 ② 条流程改，改完立刻生效
