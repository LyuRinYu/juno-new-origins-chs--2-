# 开发指南

## 前置条件

- Windows 10 / 11
- Python 3.10+
- 一份 Juno: New Origins（用于读取官方英文源；本项目**不包含**游戏文件）
- 可选：.NET SDK 10（仅重编译 `dll-patch/` 时需要）

## 从零构建

```bash
# 0. 确认游戏语言目录存在（游戏至少运行过一次）
#    %USERPROFILE%\AppData\LocalLow\Jundroo\SimpleRockets 2\Languages\EN-US\Strings.xml

# 1. 校验现有译文
python scripts/build_zh_cn.py --check

# 2. 构建 + 安装语言包
python scripts/build_zh_cn.py

# 3. 术语一致性扫描（抓跨批次用词不一致 / 漏译）
python scripts/consistency_check.py --tsv

# 4. 生成发行包
python scripts/build_package.py     # -> dist_build/*.zip
```

## 从零翻译一个新模块

```bash
# 1. 按 450 条一批切分待翻译条目
python scripts/make_batches.py      # -> batches/batch_XX.json

# 2. 翻译批次，产出 batches/batch_XX.zh.json（格式: {"键": "译文"}）

# 3. 校验单个批次
python scripts/verify_batch.py batches/batch_01.zh.json

# 4. 合并全部批次
python scripts/merge_batches.py

# 5. 构建
python scripts/build_zh_cn.py
```

## 校验规则从哪来

`checklib.py` 里的规则全部来自对游戏代码的逆向确认（`ModApi.Locale` /
`Assets.Scripts.Ui.FontCache`），不是猜测：

- `Locale.ParseStringLocales` 只读 `<s id>`，并会把值里的**字面 `\n`** 换成真换行
- 未翻译的键由 `EnsureFallbackStringLocales` 回落 EN-US
- `Fonts.xml` 的 `atlasPopulationMode` **默认是 Static**，中文必须显式写 `Dynamic`
- 语言字体自动挂到 Roboto / Pirulen 的 fallback 链，所以标题栏中文无需额外配置
- 英文源里有 11 个 id 自带 `&` 或 `'`，**XML 转义时 id 也必须转义**，
  否则整个 `Strings.xml` 非法 → 语言包整体失效（表现为"汉化突然全变英文"）

## 字体

`scripts/prepare_font.py` 从系统的 `NotoSansSC-VF.ttf` 实例化出静态字重。
**不要用变量字体（VF）**，TextMeshPro 对其支持不稳定；也不要用系统 SimHei ——
它是 Microsoft supplied font，许可禁止修改再分发。

## DLL 署名补丁

`dll-patch/` 是一个 Mono.Cecil 小工具，在主菜单版本号赋值处插入字符串拼接：

```
ldstr "v" → get_VersionWithSuffix() → Concat → Format
ldstr "  ·  LyuRinYu汉化"     ← 插入
call Concat(string,string)     ← 插入
callvirt TMP_Text::set_text    ← 赋值
```

编译与使用：

```bash
cd dll-patch
dotnet build -c Release
# 预览（不写入）
JnoSig.exe "<游戏>/SimpleRockets2_Data/Managed/SimpleRockets2.dll"
# 写入（自动备份为 .orig）
JnoSig.exe "<...>/SimpleRockets2.dll" --write
```

> ⚠ **重要**：修改 DLL 时**绝不能直接写原路径** —— Cecil 会先截断目标文件，
> 中途异常就会把 dll 变成 0 字节（游戏直接打不开）。正确做法是写临时文件、
> 回读校验通过后再覆盖。安装脚本 `packaging/install.ps1` 已实现这套流程。
